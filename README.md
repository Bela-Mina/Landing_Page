## What I Practiced

* Structuring a webpage with semantic HTML
* Creating layouts with Flexbox
* Using `flex-direction`
* Using `justify-content` and `align-items`
* Using `flex-wrap`
* Using `gap`
* Working with spacing and the box model
* Creating responsive layouts
* Organizing CSS selectors and styles

## Project Goal

The goal of this project was to practice building a realistic webpage from scratch using HTML and CSS without following a step-by-step tutorial.

## What I Learned

This project helped me understand how Flexbox controls the layout of a container's direct children and how properties such as `flex-direction`, `justify-content`, `align-items`, and `flex-wrap` work together.
